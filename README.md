# missnocall.co

The MissNoCall website, published by Netlify from this repository.

- `/` home page, `/medspa/`, `/privacy.html`, `/terms.html`
- `/studio/` Demo Studio (PIN), `/try/` demo link for prospects
- `/quote/` Quote Calculator (PIN)

Every push to `main` goes live on missnocall.co in about a minute.
Don't drag folders onto Netlify any more: a manual upload would be overwritten by the next push.
